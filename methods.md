# 2.X Gene Family Construction

## 2.X.1 Iterative Clustering Pipeline

Gene families were constructed using an iterative clustering and pruning pipeline ("family_finder") developed for this study. The pipeline addresses a fundamental limitation of single-pass ortholog inference: a single round of sequence clustering frequently mis-assigns genes, particularly those that are fast-evolving, derived from incomplete or erroneous annotations, or displaced into oversized orthogroups by spurious pairwise similarity hits. By pruning phylogenetically misplaced genes from each round and re-submitting them for clustering, the iterative approach provides displaced sequences with additional opportunities to group with their true orthologs.

The input dataset comprised 143,961 protein-coding genes from five entries representing four species (three cacti and an Aizoaceae outgroup) plus one alternative annotation: *Mesembryanthemum crystallinum* (Mcry; 25,226 genes; MAKER annotation), *Carnegiea gigantea* (Cgig; 29,163 genes; MAKER annotation), *C. gigantea* (CgigH; 27,583 genes; Helixer deep-learning annotation), *Opuntia cochenillifera* (Ococ; 33,745 genes; MAKER annotation), and *Opuntia basilaris* (Obas; 28,244 genes; MAKER annotation). The Helixer re-annotation of the *C. gigantea* genome was included as a separate entry to cross-validate gene recovery between evidence-based and deep-learning gene prediction methods. In the species tree, Cgig and CgigH were placed as sister taxa with a near-zero branch length of 0.01 substitutions per site, reflecting that they represent the same genome rather than distinct species. The full topology was ((Mcry:0.5,(Cgig:0.01,CgigH:0.01):0.49):0.3,(Ococ:0.2,Obas:0.2):0.3), with *M. crystallinum* (Aizoaceae) serving as the outgroup to the cactus clade and the two *Opuntia* species forming a sister pair within Opuntioideae.

The branch lengths of this initial tree were provisional hand-assigned values. The species tree was subsequently re-estimated from the data itself: 500 single-copy gene families (sampled from the 4,373 single-copy five-species families produced by the pipeline run) were concatenated into a codon supermatrix of 901,281 sites, and branch lengths were estimated with IQ-TREE under GTR+G with 1,000 ultrafast bootstrap replicates — the same model family as the FastTree gene trees (-nt -gtr -gamma), so that observed and expected distances in the pruning ratio (Section 2.X.3) are measured in commensurate substitution-rate units. Both internal nodes received 100% bootstrap support. A BUSCO-derived marker set was considered first but was unusable (the available BUSCO runs were genome-mode, yielding genomic coordinates rather than protein identifiers); the output file prefix retained on the computing cluster (`species_tree_busco.*`) is therefore a historical misnomer — the markers are the pipeline's own single-copy families, not BUSCO genes. The estimated tree, (Mcry:0.231,(Cgig:0.008,CgigH:0.002)100:0.045,(Obas:0.009,Ococ:0.009)100:0.044), corrected two artifacts of the hand-written values: the outgroup became equidistant to all cactus entries (patristic distance 0.278–0.284, versus the hand-written 1.00/1.30 asymmetry), and the *Ococ*–*Obas* distance, overestimated 22-fold by hand (0.40), fell to 0.018 — the congeneric *Opuntia* pair is nearly as close as the same-genome Cgig/CgigH pair. The estimated tree was adopted for all subsequent runs; the analysis reported in Sections 2.X.4–2.X.5 used the hand-written tree.

Each round of the pipeline began by partitioning the current sequence pool into per-species FASTA files and running OrthoFinder v3.1.3 (Emms & Kelly 2019), which performed an all-versus-all DIAMOND v2.1.24 (Buchfink et al. 2015) search among protein sequences followed by Markov clustering (MCL) to define orthogroups. Orthogroups containing fewer than four genes were excluded from further processing in that round, and their constituent sequences were returned to the outlier pool. All remaining orthogroups were processed independently in parallel through the alignment, tree construction, and pruning stages described below. Genes confirmed as correctly placed within their orthogroup were stored as finalized families; genes identified as outliers were collected into a pool that served as input for the subsequent round.

## 2.X.2 Per-Orthogroup Processing

Protein sequences within each orthogroup were aligned using MAFFT v7.505 (Katoh & Standley 2013) with the --auto flag, which selects the appropriate algorithm based on input size (FFT-NS-2 for larger groups, L-INS-i for smaller ones). The resulting protein alignment was then used as a guide for codon-level alignment via pal2nal (Suyama et al. 2006), which back-translates the protein alignment to nucleotide coordinates while preserving the reading frame and ensuring that indels respect codon boundaries. This protein-guided approach was preferred over direct nucleotide alignment to avoid frameshift-induced misalignment.

Prior to codon alignment, the pipeline filtered out genes whose protein sequences contained internal stop codons (asterisk characters not at the C-terminus), as these indicate annotation errors such as frameshifts or pseudogene mis-predictions and cause pal2nal to fail. In the five-species dataset, 161 *O. cochenillifera* genes and 15 *M. crystallinum* genes (approximately 0.12% of total input) were affected. Filtered genes were logged and excluded from codon alignment; when codon alignment failed entirely for an orthogroup due to insufficient remaining sequences, the pipeline fell back to protein-based tree construction.

Gene trees were inferred using FastTree v2.1 (Price et al. 2010). For codon alignments, the general time-reversible model with gamma-distributed rate heterogeneity was applied (FastTree -nt -gtr -gamma). When codon alignment was unavailable and the protein alignment was used instead, FastTree was run in protein mode with the JTT+CAT model and gamma correction (FastTree -gamma). Codon-based trees were preferred because synonymous substitutions, visible only at the nucleotide level, provide additional phylogenetic signal that protein alignments discard. This is particularly important for recently diverged species such as *O. cochenillifera* and *O. basilaris*, where protein sequences may be nearly identical but codon usage patterns have diverged measurably.

## 2.X.3 Species-Aware Pruning

Phylogenetically misplaced genes were identified and removed from each orthogroup using a species-aware distance ratio algorithm. For each gene *i* in the gene tree, the outlier score was computed as:

S(*i*) = median over all *j* where *j* is not equal to *i* and sp(*i*) is not equal to sp(*j*) of [ d_obs(*i*, *j*) / d_exp(sp(*i*), sp(*j*)) ]

where d_obs(*i*, *j*) is the pairwise patristic distance between genes *i* and *j* in the gene tree, d_exp(sp(*i*), sp(*j*)) is the pairwise patristic distance between the species of genes *i* and *j* in the species tree, and sp(*i*) denotes the species assignment of gene *i*. Same-species comparisons (paralogs within one species) were excluded from the calculation, and pruning was only applied to orthogroups containing genes from at least three species to ensure sufficient interspecific comparisons. Genes with S(*i*) exceeding a threshold of 5.0 were classified as outliers and removed from the orthogroup.

Several design choices in this algorithm merit justification. Pairwise patristic distances were used rather than root-to-tip distances to ensure that the metric is independent of tree rooting, which is often uncertain for gene trees. The ratio to species tree distance normalizes for expected phylogenetic divergence, so that gene pairs from distantly related species (e.g., *M. crystallinum* and *O. cochenillifera*, with a species tree distance of approximately 1.0 substitutions per site) are not systematically scored higher than pairs from closely related species (e.g., Cgig and CgigH, with a distance of 0.02). The median was chosen over the mean because it is robust to individual outlier pairs: a single misplaced gene elsewhere in the tree does not inflate the score for an otherwise correctly placed gene. The threshold of 5.0 requires that a gene's median observed-to-expected distance ratio exceed fivefold the species tree expectation before removal, providing a conservative filter that avoids excessive pruning. Later pipeline revisions replaced this absolute criterion with a relative one — terminal branch lengths subtracted before scoring, scores normalized by the per-family median, and a dual threshold (relative ratio plus an absolute score floor) — which is insensitive to the overall scale of the species tree and to near-zero expected distances such as the Cgig/CgigH pair; the analysis reported here used the absolute criterion with threshold 5.0.

After pruning, the confirmed members of each orthogroup were re-aligned (MAFFT protein alignment followed by pal2nal codon alignment) and a clean gene tree was reconstructed. This re-alignment step removes alignment artifacts introduced by the now-removed outlier sequences, producing curated alignments and trees suitable for downstream evolutionary analyses.

## 2.X.4 Convergence and Iterative Rounds

The iterative loop terminated when any of three convergence criteria were met: (1) the maximum number of rounds (10) was reached; (2) no new families were produced for two consecutive rounds, indicating that the pipeline had stabilized; or (3) the outlier pool dropped below five sequences, indicating exhaustion of the unplaced gene pool.

In the five-species analysis, the pipeline ran for all 10 rounds. Round 1 produced 16,250 families from the full input of 143,961 sequences, capturing 92.3% of the final family count. Subsequent rounds (R2 through R10) added 1,346 additional families for a cumulative total of 17,596 confirmed gene families. The outlier pool decreased from 23,707 sequences after round 1 to 13,963 after round 10, at which point it had stabilized. The majority of remaining outliers belonged to orthogroups with fewer than four members (below the minimum size threshold) or represented species-specific orphan genes with no detectable homologs in the panel.

The iterative approach proved essential for recovering biologically important gene families. An estimated 33 CAM (Crassulacean Acid Metabolism) pathway genes were placed into correct families only through rounds 2 through 10, having been pruned as outliers or misassigned during round 1. Notable examples included NADP-Me3, Snrk2.3, CIPK24, Ers1/Etr1, and Myb61 (recovered in rounds 2 through 4) and Hkl1 (recovered in round 9). These genes would have been lost or incorrectly assigned in a single-pass OrthoFinder analysis.

## 2.X.5 HMMER Profile-Based Rescue

After convergence of the iterative clustering pipeline, 13,963 genes (9.7% of the input) remained unplaced. Many of these were expected to be true members of confirmed families but too divergent for DIAMOND pairwise sequence comparison to detect homology. To recover these genes, we employed a profile-based rescue strategy using HMMER v3.2.1 (Eddy 2011).

HMM profiles were built from the confirmed protein alignments of all 17,596 families using hmmbuild. The unplaced gene sequences were then searched against the complete set of family profiles using hmmsearch with an E-value threshold of 1 x 10^-5. Each gene was assigned to the family producing the lowest E-value hit, provided that the hit fell below the threshold. Genes assigned to existing families through this rescue step were incorporated into their respective families, after which the affected families were re-aligned and their gene trees were reconstructed to account for the new members.

This approach rescued 6,358 genes (45.5% of the unplaced pool) into existing families. The rescued genes were distributed across all five species: *O. cochenillifera* (1,692 genes), *C. gigantea* Helixer (1,573), *O. basilaris* (1,262), *C. gigantea* MAKER (1,099), and *M. crystallinum* (732). The disproportionate number of rescued genes from *O. cochenillifera* and CgigH is consistent with the higher fragmentation and divergence observed in those annotations.

The biological significance of the HMMER rescue step was demonstrated by its recovery of CAM pathway genes that had eluded all 10 rounds of iterative DIAMOND-based clustering. Of nine initially unplaced *M. crystallinum* CAM genes, eight were successfully assigned to existing families by HMMER: Mcr2G22880 (CKB1; E = 1.7 x 10^-147), Mcr4G10250 (Pfk5; E = 2 x 10^-158), Mcr1G03910 (Nst; E = 5.2 x 10^-76), Mcr1G01450 (VhaE; E = 8.5 x 10^-73), Mcr5G24020 (VhaB; E = 1.4 x 10^-59), Mcr1G10640 (Cbl3; E = 3.7 x 10^-34), Mcr9G21470 (Lda1; E = 1.2 x 10^-9), and Mcr5G21920 (FAR1; E = 2.6 x 10^-8). The single unrescued gene, Mcr4G19500 (Gln1/Gln2), was a truncated gene model of only 78 amino acids, below the length at which profile-based methods can reliably establish homology.

The success of the HMMER rescue step reflects a fundamental difference between pairwise and profile-based homology search strategies. DIAMOND compares individual sequence pairs and requires that a query share sufficient similarity with at least one database sequence to produce a significant hit. For highly divergent homologs, no single pairwise comparison may exceed the significance threshold even when the gene clearly belongs to the family based on its overall domain architecture. HMM profiles, by contrast, encode position-specific amino acid frequencies and gap penalties derived from the entire multiple sequence alignment of a family, enabling them to detect conserved structural and functional motifs even in sequences that have diverged substantially from any individual family member.

## 2.X.6 Subfamily Delineation and Attribution

Within confirmed families, subfamilies were defined as hierarchical orthogroups (HOGs): clades of the family gene tree delimited by its duplication nodes, so that each subfamily comprises the descendants of a single gene copy present in the family's last common ancestor (Fernández et al. 2020). Two independent tree-partitioning methods were applied to each family gene tree. Possvm (Grau-Bové & Sebé-Pedrós 2021), which identifies duplication nodes by the species-overlap criterion and groups the resulting ortholog groups by Markov clustering, served as the primary duplication-aware partitioner; trees were pre-rooted on an outgroup clade, curated reference genes were supplied as labeled anchor leaves, and only nodes with support of at least 95 were used for splitting (-min_support_node 95). TreeCluster (Balaban et al. 2019) in max_clade mode (support threshold 0, distance threshold 1.0) provided a support-constrained, distance-based cross-check.

The two methods were validated against each other and against a baseline greedy clade rule (maximal clades with ultrafast bootstrap >= 95) on a 102-sequence phospho*enol*pyruvate carboxylase (PEPC) clan reference including *Arabidopsis thaliana* and *Ananas comosus* anchor sequences. All three partitions nested perfectly with zero boundary conflicts, cutting a single consistent hierarchy at different depths (family, 3 subfamilies, ~30 ortholog groups), and every method recovered the biologically decisive subfamily — a 10-member clade carrying the dominant expression signal — identically (exactly, 10/10 members, by Possvm). Subfamily boundaries were therefore taken from the gene tree; structural comparison, which merges the entire clan into one cluster, was used only as a family-membership channel, never to delineate subfamilies. That comparison was made on the clan as first assembled; the sequence set was subsequently re-derived and verified against the source genomes (below), and the partition comparison was not repeated on the corrected set.

Each subfamily split was then attributed as lineage-specific or as an ancient paralog split, using the species tree as the primary evidence. The subfamily's species set was tested for monophyly in the species tree and its most recent common ancestor (MRCA) identified: a species set forming a clade strictly inside the family's own species span was called lineage-specific, whereas a non-monophyletic species set — or one whose MRCA coincides with the MRCA of the whole family (the root-span rule) — was called a paralog split. The root-span rule prevents ancient paralog pairs retained in all sampled species (such as plant-type Ppc1/Ppc2) from being misclassified as lineage-specific merely because their species set is trivially monophyletic. An external taxonomy table assigning rank labels to species (e.g., "Cactaceae (family)") was used only as an optional labeling layer on top of this verdict, not as the evidence for it. Two supporting diagnostics accompanied each attribution: a specificity-determining-position (SDP) scan reporting alignment columns at which one subfamily is conserved for a residue rarely used by the rest of the family (with positions expressed in reference-sequence coordinates, e.g., *A. thaliana* PPC1 numbering), and a structural-coherence test comparing mean within-subfamily versus between-subfamily Foldseek all-versus-all scores.

This SDP diagnostic was validated on the plant-type PEPC paralog split — the case the root-span rule was written for — and the validation is reported here because it also bounds what the diagnostic can and cannot establish. Subfamily membership was taken from the rebuilt 95-sequence clan tree inferred from codon positions 1+2+3 under a position-partitioned model, after the sequence set itself had been corrected against the source genomes (described below), on which the two plant-type subfamilies are recovered as disjoint clades: ppc-1E1, carrying the *M. crystallinum* Ppc1 anchor Mcr8G11630 (SwissProt P10490), with 62 members across 15 sampled species and both anchor species at SH-aLRT 95 / ultrafast bootstrap 91; and ppc-1E2, carrying the Ppc2 anchor Mcr7G08600 (P16097), with 15 members across 10 species at 100 / 76. Because ppc-1E2 falls below the conventional bootstrap criterion of 95 applied elsewhere in this section, residue-level evidence was sought that does not derive from node support. Trimmed matrices were used for tree inference only. Reading residues does not re-estimate the topology, and the occupancy-based column filters that help tree inference delete precisely the gappy N-terminal regulatory regions that residue-level questions are about, so every scan reported here was run on the untrimmed 1,428-column amino-acid alignment, restricted to the 77 plant-type sequences so that the contrast set for each subfamily is exactly the other subfamily rather than the remainder of the clan. Under the default criteria (at least 80% within-subfamily conservation, at most 20% of the contrast set carrying the same residue, at least 70% non-gap coverage), ppc-1E1 yielded 31 diagnostic columns and ppc-1E2 yielded 56; 26 columns were reciprocal, with both subfamilies fixed on different residues at the same site. Restoring the 18 bacterial-type (ppc-2/BTPC) outgroup sequences to the contrast set left the counts in the same range (24 and 51), indicating that the same residues also separate each plant-type subfamily from the bacterial-type clade.

Positions are reported in full-length *M. crystallinum* Ppc1 (P10490, 966 residues) numbering. The N-terminal regulatory phosphorylation motif SIDAQL (residues 11–16) is present in the untrimmed alignment but is covered by only 32 of the 62 ppc-1E1 members, so the 70% coverage requirement suppresses ppc-1E1 columns there; the absence of ppc-1E1 diagnostic columns in the N-terminus is a property of that filter rather than of the sequences, and is reported by a companion coverage audit rather than left silent. The motif itself is retained intact in both subfamilies — the phospho-serine at residue 11 is present in 15 of 15 ppc-1E2 members and in 29 of the 32 ppc-1E1 members that cover the region — so neither subfamily has lost the capacity for phosphoregulation. Its immediate context differs: residue 9, two positions N-terminal of the phospho-serine, is methionine in all 15 ppc-1E2 members and leucine in the ppc-1E1 majority (26 of 32), and residue 10 is fixed as alanine in all 15 ppc-1E2 members while ppc-1E1 is split between alanine (13) and serine (9) with no consensus. Because the residues flanking the phosphorylated serine contribute to recognition by PEPC kinase, this substitution is reported as a testable candidate for differential phosphoregulation, not as an established functional difference. Of the conserved motifs retained — GYSDSGKDAGR (595–605), FHGRGG (633–638), and the C-terminal QNTG tetrapeptide (963–966) — none contains a diagnostic column; the nearest lies at residue 611, six residues C-terminal of GYSDSGKDAGR (ppc-1E1 Q at 94%, ppc-1E2 A at 100%). The diagnostic residues therefore avoid the catalytic core, as expected of a paralog split that preserves enzyme function. Two null models were used to calibrate the counts. Five hundred random ppc-1E1 subsets matched to ppc-1E2 in size (15) and species breadth (10) yielded a median of 0 diagnostic columns and a maximum of 1, so the observed count is not an artifact of the small and unbalanced group sizes (empirical p < 0.002). However, the 23 *monophyletic* ppc-1E1 subclades of at least five members yielded 7 to 79 diagnostic columns, which shows that monophyly alone generates them: the scan and the tree read the same alignment, and the diagnostic is consequently corroborative rather than independent. What separates the two cases is species breadth. The SDP-rich null subclades are species-poor tandem arrays (7 sequences from 2 species, 79 columns; 6 from 2, 75), where shared residues reflect recent common ancestry within one or two genomes, whereas the broadest comparators — 57 members from 13 species, and 43 from 10 — yield only 25 and 21. ppc-1E2 spans 10 species and yields 56, exceeding every comparator of comparable or greater breadth, the largest of which reaches 37 at 9 species. Its diagnostic residues are accordingly consistent with an ancient split followed by independent fixation in both lineages, and ppc-1E2 is reported as an adopted subfamily with its support values stated, not as one established at the 95 threshold.

The clan sequence set required correction before any of this could be trusted. Six of its members carried an `_M` suffix and no recoverable provenance: full-length PEPC proteins of 801–1,042 residues that had been substituted at an earlier recruitment step for truncated deposited gene models of 250–834 residues. A protein that is not encoded by the genome it is attributed to will still place somewhere in a tree, so each was aligned back to its own species' assembly. Four matched their nominal genome at 0.982–0.997 identity, within the loss expected from splice-boundary and frameshift artifacts of protein-to-genome alignment; two did not (0.855 and 0.790) and are not genes of the species they were labelled with. The set was therefore rebuilt rather than patched. The 94 clan members of at least 800 residues that carried no `_M` suffix were re-predicted against all five cactus genomes with miniprot, and a predicted model was accepted only if it aligned to the genome it had been predicted from at at least 0.95 identity — the criterion being which genome a model belongs to rather than a fixed similarity cutoff, since ordinary interspecific divergence can breach any such cutoff. Of 49 loci recovered, 44 were accepted and 5 rejected at 0.83–0.90. Five `_M` sequences were replaced by reconstructions from their own genomes and one was removed for having no accepted counterpart, giving a corrected set of 108. Realignment and a 50% column-occupancy filter removed 9 further sequences, every one of them a truncated model of 575–683 residues, while all five replacements passed at occupancies of 0.674–0.687. Codon alignment succeeded for 95 of the remaining 99: miniprot's translated output skips frameshifts and so does not correspond one-to-one with the CDS intervals of its own GFF, and the four affected reconstructions were consequently excluded from the codon matrix while retained in the protein alignment. Frameshifted predictions are rejected by default for this reason.

The two plant-type subfamilies are distributed very unevenly across Cactaceae, and the distribution is graded by gene-model completeness rather than being a clean presence or absence. Only one of the 15 ppc-1E2 members is a cactus — *O. basilaris* `JBFLFP010000004.1_000494`, a full-length 967-residue protein identical to its deposited annotation — but two further cactus loci lean to ppc-1E2 and were excluded by the occupancy filter rather than by the tree. In *O. cochenillifera* the locus on chromosome 10 at 36.21–36.23 Mb, the position previously occupied by one of the unverifiable `_M` sequences, does exist: it was reconstructed at 0.985 identity to its own genome, but the resulting model is 683 residues, short of full length by roughly 270 N-terminal residues including the SIDAQL motif, and covers 47.8% of alignment columns against the 50% threshold. It is the only one of the 15 *O. cochenillifera* PEPC loci whose profile score leans to ppc-1E2 (+156 bit scores, against −228 to −552 for the rest). In *C. jamacaru* the orthologous interval is recovered intact by synteny with *O. cochenillifera* chromosome 10, using the pairwise MCscan anchor sets: the genes immediately flanking the *O. cochenillifera* locus anchor to `JBOBQE010000004.1` at 16.96 Mb and 15.77 Mb, and a single unanchored gene, `JBOBQE010000004.1_002232`, lies between them at 16.03 Mb, leaning to ppc-1E2 by +61 bit scores but encoding only 411 residues against a full-length PEPC of approximately 966. The margin scales monotonically with model length across the three loci (967 residues, +251; 683, +156; 411, +61), which reads as one locus retained in different states of truncation rather than as three independent observations.

In *S. undatus* the flanking genes anchor to chromosome 4, which carries none of the fifteen PEPC-like genes detected in that genome; the strongest ppc-1E2-leaning candidate exceeds its ppc-1E1 score by two bit-score units and is a full-length bacterial-type protein. Loss is the more parsimonious reading, with the caveat that the anchors span 23 Mb and do not define a tight block. No conclusion is drawn for *C. gigantea*: its assembly comprises 2,589 scaffolds, only 52% of *O. cochenillifera* chromosome 10 genes anchor to it at all (against 67% and 69% for the other two genomes), no anchor falls within the 25-gene window examined, and only seven PEPC-like genes are detected against 13 to 22 elsewhere. The absence of a candidate there reflects assembly and annotation completeness rather than evidence of loss. ppc-1E2 is therefore present across Cactaceae but reduced to a truncated model in most sampled lineages, with only *O. basilaris* retaining a full-length copy. Its tree-based membership rests on that single cactus; the *O. cochenillifera* and *C. jamacaru* loci are reported on synteny, profile margin and locus reconstruction, which are evidence from outside the tree.

## 2.X.7 Functional Annotation and Naming of Families

Confirmed families were annotated along four independent axes: enzymatic function (EC numbers), structure-based function transfer, subcellular localization signals, and gene names. Each axis was validated with a known-answer gate on the PEPC clan, whose expected annotation (EC 4.1.1.31, phospho*enol*pyruvate carboxylase) is unambiguous. All four axes are annotation layers over the homology-defined families: none was used as a clustering criterion or as a filter on family membership.

EC numbers were derived from two complementary sources. eggNOG-mapper v2.1.15 (Cantalapiedra et al. 2021) transferred EC numbers and gene symbols by orthology (DIAMOND search mode against the eggNOG database); it provides traceable orthology-based evidence but no confidence value. CLEAN (Yu et al. 2023), a contrastive-learning EC predictor operating on ESM-1b protein language model embeddings, always emits an EC call whose confidence carries the signal: core family members scored 0.986–0.996 while remote members dropped toward zero. Both tools passed the known-answer gate (all 7 *A. thaliana* and *A. comosus* PEPC anchors assigned EC 4.1.1.31; eggNOG-mapper additionally recovered the correct PPC1/PPC4 gene symbols). A previously evaluated predictor, ESM-ECForest, failed the same gate — the expected EC was never predicted among 102 clan sequences, an anchor was misclassified as a non-enzyme, and its probabilities were uniform noise — and was rejected. Predictions from the two accepted sources were merged per gene with the eggNOG-mapper EC call authoritative, the CLEAN confidence attached, and an agreement flag recorded. One caveat, measured on a tandem array of degenerate PEPC copies: no sequence-, orthology-, or structure-based source detected residue-level catalytic loss — genes lacking the PF00311 domain and the catalytic histidine still received high-confidence EC 4.1.1.31 calls from every tool. EC assignments were therefore reported as annotations to be read alongside domain and catalytic-residue evidence, never used to include or exclude genes.

For structure-based function transfer, ESMFold-predicted structures of family members were searched with Foldseek easy-search (van Kempen et al. 2024) against the AlphaFold–SwissProt structure database (maximum 30 target sequences, E < 1 x 10^-5, TM-score output enabled), and the best hit's UniProt annotation (protein name, gene symbol, EC number, GO terms) was joined via the UniProt REST API. On the known-answer gate, 99 of 100 PEPC-clan hits carried EC 4.1.1.31, and the two *M. crystallinum* query genes recovered their own species' curated SwissProt entries (P10490/Ppc1 and P16097/Ppc2) at sequence identity 1.000 and TM-scores of 0.95 and 0.92, respectively.

Subcellular localization signals were predicted with DeepLoc 2.1 (run once per proteome, retaining the full class-probability vector rather than only the argmax label so that dual targeting is not flattened away; its sorting-signal predictions cover nuclear localization and export signals, transit peptides, and signal peptides) and with SignalP 6 (Teufel et al. 2022; secretory signal peptides only, fast model). The two tools probe complementary axes and were cross-validated on the 102-sequence PEPC clan with zero contradictions: SignalP predicted no secretory signal peptide anywhere in the clan, consistent with a cytosolic enzyme family, while every DeepLoc sorting signal was a nuclear-transport signal outside SignalP's scope.

Families and subfamilies were named by combining two evidence layers in a weighted majority vote over member gene descriptions. The direct layer mapped a curated annotation table for one well-annotated species (*M. crystallinum*) onto family and subfamily assignments. The orthology layer transferred *A. thaliana* gene symbols and descriptions per gene by DIAMOND best-hit search against the PLAZA Dicots *A. thaliana* proteome, with transcripts collapsed to genes and reciprocal-best-hit (RBH) status computed per query species (reverse best hits evaluated species-by-species, preventing phylogenetically closer species from masking others' reciprocals in a pooled database); across the five-entry panel this yielded an *A. thaliana* ortholog for 109,891 genes, 50,153 of them (45.6%) reciprocal best hits. In the vote, direct annotation outweighed orthology transfer (weights 1.0 versus 0.5), and every assigned name carried a provenance record (direct versus orthology) and a support fraction. RBH status was reported as an evidence column rather than applied as a filter, because in multi-copy families at most one gene per species can be a reciprocal best hit by construction.

## 2.X.8 Annotation Heterogeneity and the Interpretation of Unplaced Rates

Per-species unplaced rates cannot be compared directly across the panel, because the input proteomes were produced by different annotation pipelines applying different minimum-length policies. The *C. gigantea* MAKER annotation contains no protein shorter than 151 amino acids, whereas the *M. crystallinum* annotation retains proteins as short as 3 amino acids, 3,374 of which (13.4% of that proteome) fall below 100 amino acids. Because short models are substantially harder to place — 60.1% of *M. crystallinum* proteins below 100 amino acids remained unplaced, against 6.2% of those at or above that length — the raw unplaced rate measures annotation policy as much as pipeline behaviour.

The two panels are not annotation-matched: the five-species panel uses the *C. gigantea* MAKER annotation (29,163 proteins) while the fifteen-species panel uses the Helixer annotation of the same genome (27,583), so *C. gigantea* figures are not comparable between them. The older annotation is retained in the five-species panel deliberately, because the two annotations of one genome are what make the length-policy control below possible.

We therefore report unplaced rates stratified by protein length, and additionally assessed the structural integrity of each gene model by requiring an ATG start codon, a terminal stop codon, a coding sequence length divisible by three, and no internal stop codon. The two *C. gigantea* annotations provide an internal control: Helixer produced 3,132 proteins shorter than 100 amino acids on the same genome for which MAKER produced none, and 99.2% of them satisfied all four structural criteria. A large short-protein population is therefore an annotation policy difference rather than evidence of spurious gene models. By contrast, only 75.4% of the short *M. crystallinum* models were structurally intact (10.1% carried internal stop codons), against 99.2% for *C. gigantea* Helixer, 99.9% for *O. basilaris* and 94.6% for *O. cochenillifera*. The *M. crystallinum* protein-length distribution also shows a distinct mode at 80-90 amino acids, with density declining thereafter, a shape not observed in any other panel proteome, where density through this range is flat or rising.

Restricting the comparison to proteins of at least 100 amino acids that satisfy all four structural criteria, the *M. crystallinum* unplaced rate is 5.0% (1,028 of 20,446), against 2.5% for *C. gigantea* MAKER, 2.6% for *O. cochenillifera* and 3.2% for *O. basilaris*. The apparent two- to five-fold excess in the raw rates therefore reduces to approximately 1.6- to 2.0-fold once annotation differences are accounted for. The residual excess is consistent with *M. crystallinum* being the sole representative of Aizoaceae in the panel: it has no close relative against which a homolog can be detected, whereas each cactus has three. We report this residual as an irreducible property of the taxon sampling rather than a deficiency of the clustering procedure. The *C. gigantea* Helixer annotation is a valid control for annotation quality but not for placement rate, because it was excluded from clustering (Section 2.X.1) and reached families only through profile assignment and rescue.

Short gene models were further assessed by exon structure, using the two *C. gigantea* annotations as an internal control. Among structurally intact proteins shorter than 100 amino acids, 58.6% of *M. crystallinum* models (1,489 of 2,543) are single-exon, against 28.3% for the *C. gigantea* Helixer annotation (878 of 3,106) and 39.4% for *O. cochenillifera* (645 of 1,636); the corresponding figures for proteins of at least 100 amino acids are 21.2%, 18.7% and 19.4%, so the difference is specific to the short class. Taking the Helixer annotation as the baseline for a trustworthy short-model population, the excess amounts to approximately 770 models, or 488 against the *O. cochenillifera* baseline. Short models nested entirely within a longer gene are also enriched in *M. crystallinum* (4.4%, against 1.9% and 1.0% in the two controls), contributing a further ~60 models that largely overlap the single-exon set. A transposable-element screen was attempted but is not reported: the only available library was built from *Opuntia*, so hit rates track phylogenetic distance to the library rather than element content, and the cactus control is closer to it than the focal species.

Combining these lines of evidence with the structural-integrity criteria, approximately 1,300 to 1,600 of the 3,374 short *M. crystallinum* models (39-47%) are not defensible as gene models, and the remainder are ordinary short proteins. Removing structurally broken models lowers the raw unplaced rate from 13.4% to 10.9%, and additionally removing the excess single-exon short models lowers it to 8.7%. These corrections do not alter the length-stratified comparison above, which was already restricted to intact proteins of at least 100 amino acids; that residual excess of 1.6- to 2.0-fold is unaffected. Short models remain harder to place even when well supported — intact multi-exon models below 100 amino acids are 45.6% unplaced against 5.0% for intact models at or above that length — so a length-dependent penalty is expected independently of annotation quality.

The same confound governs intron-level gene-structure metrics, and more severely. Measured on the PEPC clan, the fraction of gene models departing from the family's canonical intron count tracks the annotation program rather than the subfamily: 0.52 for Helixer-annotated genomes, 0.39 for EVM, and 0.00 for AUGUSTUS and the UNR in-house pipeline on the same gene family. An uncontrolled cross-species comparison of intron metrics would therefore read annotation-pipeline differences as biology. Accordingly, the gene-structure annotation axis (`steps/gene_structure.py`) records the annotation program of each proteome and withholds intron-based metrics entirely whenever the program is unknown, rather than emitting numbers that cannot be compared; exon-count and length-based metrics, which proved robust to this confound in the two-annotation *C. gigantea* control, are reported unconditionally.

The codeml entry is deliberately blank. The pipeline's configuration files do not pin a codeml binary, so the default resolves to whichever `codeml` a shell happens to expose; no codeml is present on the cluster PATH the pipeline sets up, seven differing installations exist on the two hosts (PAML 4.9i through 4.10.10), and codeml prints no version banner, so a run cannot be attributed to a version after the fact. The branch-site results reported elsewhere were produced outside the pipeline path and their working directory has not been retained. A version will be stated here only once the binary is pinned in configuration and the analysis rerun from it.

Two entries in this table carry a caveat that a version number alone does not convey. Possvm is distributed as a git checkout and reports version 1.2 from two different commits; the analyses reported here used commit 1ee6113 (2024-07-19), and the commit rather than the version string identifies the code. Pipeline parameters were set as follows: maximum rounds, 10; minimum orthogroup size, 4 genes; species-aware pruning threshold (tau), 5.0; TreeShrink quantile, 0.05 (when available; TreeShrink was not used in the reported analysis due to a Python version incompatibility); convergence criterion for consecutive rounds without new families, 2; minimum outlier pool size for continuation, 5 sequences; HMMER rescue E-value threshold, 1 x 10^-5. Per-orthogroup processing was parallelized across 8 workers, and OrthoFinder was run with 8 threads for the DIAMOND search phase. The complete configuration used for the five-species analysis is provided in the file config_5sp.json in the pipeline repository.
